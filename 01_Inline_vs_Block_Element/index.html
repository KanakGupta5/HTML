Block Elements:

  • They by default take width of their parent
  • Width, height, padding and margin are respected
  • They always break on new line
  • They always stack vertically(on top of each other) irrespective of the free space
  • eg <div>, <p>, <h1>, <ul>

Inline Elements:

  • They take width of the content present in them
  • Width, height and margin(top bottom) are not respected
  • They doesn't break on new line
  • They always stack horizontally(adjacent to each other)
  • Inline elemens have two category: Replaced and Non-replaced
  • eg <span>, <a>, <b>, <i>

Inline Block Elements:

  • They by default take width of the content present in them. But they respect explicit height and width properties.
  • They respect padding/margin on all four sides.
  • Unlike block elements, they expands in the same horizontal line

Replaced Inline Elements

  • They are inline elements but behaves like inline-block
  • They respects the attributes(height, width, padding and margin) like block elements.
  • They sits in the same horizontal space like inline elements
  • Eg. <img>, <iframe>
  • Since the content of such elements is defined by external source which is out of the CSS, this elements behaves this way
